Пояснения — Wireframe

ЭлементПоле API / условиеПримечание
Список: какие папки видныGET /api/test-folders отдаёт только видимые папки; visibility = direct | transitЧужие папки без доступного содержимого, в том числе пустые, в ответ не попадают — клиенту прятать нечего
Меню «Действия с папкой»Выводится у каждой папки; «Переименовать» и «Удалить папку...» активны при canEdit = trueУ транзитной папки (visibility: transit) canEdit = false — меню открывается, все пункты неактивны (s-transit-menu)
Пункт «Общий доступ» в меню папкиАктивен при canManageAccess = true (владелец папки или администратор), иначе неактивенИконка и подпись — как у пункта меню теста (KeyRound, «Общий доступ»)
Окно «Общий доступ» папки: владелецGET /api/test-folders/:id/access → ownerId«Сменить владельца» — как у теста: кнопка заменяет строку селектом пользователей, запись по «Сохранить» через новый PATCH /api/test-folders/:id/owner (план 2). Кнопка выводится тем, у кого есть tests.owner.change, как у теста
Свои гранты папкиgrants; запись — PUT /:id/access { userId, accessLevel }, отзыв — DELETE /:id/access/:userId/:slotКак у теста: изменения копятся и применяются по «Сохранить»
Уровни в селектеedit «Редактирование», assign «Назначение»Только два уровня. «Рецензирование» выдаётся на конкретный тест, на папку — нет: сервер в плане 2 перестаёт принимать review для папки
Раздел «Унаследовано»Папка: inherited; тест: нужен новый ответ сервера с грантами цепочки папок (в плане 1 его нет)Только просмотр. Кнопка с именем папки открывает «Общий доступ» той папки; снять унаследованное можно только там. Раздел не выводится, если унаследованного нет (s-folder-access-empty)
Предупреждение в «Переместить в папку»POST /api/test-folders/move-preview при выборе папки → gainedБаннер выводится только при непустом списке. Заголовок — число, текст — имена с уровнем через запятую; больше 10 человек — первые 10 и «и ещё N». Превью должно отдавать список (gained: [{ userId, accessLevel }]), а не число — правка сервера в плане 2. «Переместить» шлёт PATCH /move/:testId с confirmGain: true; без него сервер отвечает 409 access_gain
